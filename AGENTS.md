This repository is an AI Engineer portfolio project implementing an
Enterprise IT Support Copilot.

Use PROJECT_BRIEF.md when architectural or product context is needed.

Development principles:

- Build incrementally. Do not implement future phases prematurely.
- Prefer simple, readable Python over unnecessary abstractions.
- Use type hints and Pydantic models where appropriate.
- Separate application code, data access, AI logic, and evaluation.
- Write tests for important behavior.
- Do not hard-code API keys or credentials.
- Use environment variables for secrets.
- Explain major architectural decisions before introducing significant
  dependencies.
- Keep the project realistic enough to discuss in an AI Engineer interview.
- Avoid adding libraries merely for résumé keyword coverage.
