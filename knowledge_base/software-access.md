# Software installation and access

## Approved application installation

Install approved applications through the managed Software Center. Restart if it requests a reboot, then capture the installation error code if the deployment fails. Do not download installers from advertisements, use personal administrator accounts, or disable endpoint security. Applications absent from the catalog require a software request with the business purpose and manager approval.

## Application access request

An installed application may still need membership in an access group. Request access through the service portal with the product name, requested role, project, and manager approval. The application owner approves the least-privileged role. For paid products, a license allocation may also be required. Installing the client or resetting the password does not grant permissions.

## Application crashes

Record the application version, error message, and steps that reproduce the crash. Restart the application once and check for a managed update in Software Center. Do not delete the user profile or application data without a backup and IT instructions. Escalate recurring crashes to Application Support with the affected file type and whether colleagues can reproduce them.
