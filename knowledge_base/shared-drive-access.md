# Shared drive access

## Folder permission requests

For Access denied on one project folder, request the minimum required permission from the folder's business owner. Include the exact share path, project, requested read or edit access, and business reason. The owner authorizes the service desk to update the appropriate group. Network connectivity and VPN access alone do not grant folder permission. Do not copy files through personal storage to bypass a denial.

## Share path not found

Check the exact approved share path and whether other internal services are reachable. Off-site users must connect to Corporate VPN first. If all internal destinations fail, follow VPN routing diagnostics. If other shares work but one approved path cannot be found, send the path, error, and timestamp to Storage Support. Do not guess a replacement server name.

## Drive reconnects with old credentials

If a mapped drive repeatedly requests the password after a password change, update the saved company credential with service-desk guidance and reconnect the approved mapping. Repeated old-password attempts can lock the entire account. If browser sign-in works and the drive still says Access denied, have the folder owner verify group membership rather than resetting the password again.
