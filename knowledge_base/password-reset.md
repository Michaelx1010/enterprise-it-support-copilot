# Company password resets

## Forgotten or expired password

Use the company identity portal's Forgotten password option from a trusted browser. Complete the registered verification method and choose a new unique password. If no registered verification method is available, contact the service desk for the identity-verification process; do not send identity documents or passwords by email. An expired password must be changed through the portal before trying the desktop client again.

## Update saved credentials

After a password change, sign out of the email client and VPN and sign back in with the new password. Remove outdated saved credentials for company services from the operating system credential manager with service-desk guidance. Update company accounts on mobile devices as well. A device repeatedly using an old password can trigger another account lockout even when browser login works.

## Identity verification boundary

The service desk verifies identity using the approved callback and employee-record procedure. It never asks for the current password, an MFA approval, or a recovery code in a ticket. Managers may confirm employment but cannot bypass identity verification. A lost authenticator requires the separate MFA recovery procedure before self-service password reset can succeed.
