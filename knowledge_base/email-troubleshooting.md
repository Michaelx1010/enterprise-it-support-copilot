# Email client troubleshooting

## Browser works but desktop does not sync

Compare the company webmail interface with the desktop client. If new mail arrives in webmail only, confirm the client is not in Work Offline mode and restart it once. After a password change, sign out and sign back in. Record the last successful sync, client version, and error. Do not delete the mail profile or local archive without IT guidance and a backup.

## Webmail and client both reject login

Try the company identity portal once. If it also rejects the credentials, follow the company password or account-lockout process. If an authenticator phone is unavailable, use MFA recovery. Reinstalling the email client does not fix an identity problem. Report suspected unauthorized login attempts to Security.

## Shared mailbox permissions

A shared mailbox owner must approve delegation. Submit the mailbox address and whether read access or Send As permission is needed; these are separate permissions. After IT confirms the change, restart the client and test webmail. Do not share the mailbox owner's password. If only sending fails while messages are readable, verify Send As permission specifically.
