# Repeated account lockouts

## Several applications reject login

When email, VPN, and the identity portal all reject the same account, stop repeated attempts and contact Identity Support with the username, timestamps, and error text. The service desk checks whether the account is locked, disabled, or expired. A disabled account needs an authorized owner review; repeated password resets will not re-enable it. Never submit a password or MFA code with the ticket.

## Lockout returns after reset

An old password saved in a phone, email client, mapped drive, or VPN client can repeatedly lock the account. Note which devices are online and update their saved credentials using the password-reset guidance. Ask Identity Support to inspect the source of failed sign-ins before unlocking again. Do not remove company accounts or wipe devices without approval.

## One application denies access

If the identity portal and other applications work but one product says Forbidden or Access denied, check the application's access-group membership with its owner. This is usually an authorization request, not a reason to reset the company password. For shared folders contact the folder owner; for a licensed application verify both entitlement and activation status.
