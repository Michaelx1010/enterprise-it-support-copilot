# Corporate Wi-Fi connection

## Cannot join the wireless network

Managed laptops should join Northstar-Staff. Toggle Wi-Fi once, check airplane mode is off, and verify that the device clock is correct. The staff network uses a managed device certificate, not the company account password. Certificate-expired or device-not-compliant errors go to Endpoint Support; password resets do not renew certificates. Visitors use the separately sponsored Northstar-Guest network and cannot access internal services through it.

## Connected without internet

Test a public website and ask whether nearby colleagues have the same issue. If several users on the same floor have no internet, report the floor, access point area, and time to Network Support. A home connection should be tested before opening the VPN client. Avoid forgetting the managed staff profile or changing network settings without IT guidance.

## Slow or intermittent connection

Record whether the issue follows the laptop or stays in one location. Move near an access point and compare a wired connection if available. Capture the time, floor, and affected applications. If public browsing is stable and only the remote session freezes, follow remote-desktop diagnostics. Large transfers should be paused during a comparison test, but security tools must remain enabled.
